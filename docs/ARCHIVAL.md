# Archival notice

Take Two is inactive. Development is no longer active. This repository preserves
original application source code and documentation so the project can be restored
later. It is a normal GitHub repository, not a GitHub Archived repository, but
its content is frozen except for retirement, licensing, and documentation fixes.

## What is preserved

- Web app source: `src/`, `shared/`, `worker/`, `tests/`.
- Python AI companion source: `ai/src/`, `ai/tests/`, `ai/scripts/`, `ai/README.md`.
- Documentation: `docs/` (including `ROOM_PROTOCOL.md`), `public/scenes/README.md`.
- Build/deployment configs: `package.json`, `package-lock.json`, `tsconfig.json`,
  `vite.config.ts`, `wrangler.jsonc`, `wrangler.dev.jsonc`, Playwright configs,
  `scripts/`, `.env.example`.
- Original fixtures: `public/scenes/a-small-step/` (silent development animation
  - poster) and `public/scenes/the-last-table/` posters. See
    `public/scenes/README.md` for provenance.
- `README.md` (English), `README.tr.md` (Turkish), `LICENSE` (MIT), `AGENTS.md`.

## What is excluded

- `node_modules/`, `dist/`, `.tools/` (portable Node, browsers, uv cache).
- `ai/.venv*/`, `ai/.cache/` (Python environments, model weights).
- `.wrangler/`, `.worker-build/`, `test-results/`, `local-test-media/`.
- `public/runtime/` (ffmpeg parts regenerated by `npm run runtime:prepare`).
- `.ruff_cache/`, pytest caches, credentials (`.env`, `.dev.vars`).
- `memory-bank/` (local-only internal notes, not published).

Model weights, private media, recordings, and secrets were never committed and
must not be added.

## Restoration requirements

1. Node.js 24 LTS (>= 24.15), npm. See engine ranges in `package.json`.
2. `npm ci`, then `npm run dev:all` for local Vite + Worker development.
3. `npm run build` regenerates `public/runtime/` and validates the Worker dry-run.
4. Optional AI companion: `npm run ai:setup`, gated model download with
   `HF_TOKEN` via `npm run ai:models`, then `npm run ai:dev`. See `ai/README.md`.
   Weights require separate license acceptance (notably CC BY 4.0 for
   Community-1) and multi-GB disk. CDX23 checkpoint weights remain
   license-uncertain and local-only.
5. Cloudflare redeployment (if ever needed) requires `wrangler login`, an updated
   `ALLOWED_ORIGINS`, `npm run build`, `npm run production:audit`, and
   `wrangler deploy`. No R2 binding is used. See `docs/SHUTDOWN_CHECKLIST.md`
   before touching the historical deployment.

## Historical deployment

Worker `take-two-rooms` was deployed on 2026-09-13 to
`https://take-two-rooms.take-two.workers.dev` with SQLite `ROOMS`,
`SCENE_STUDIO`, `MEDIA_STORE` and 14 Static Assets, zero R2 bindings. Remote
smoke and same-machine Chrome acceptance passed. Different-home multiplayer
acceptance never ran. Shutdown is planned after GitHub publication is verified;
it is not implemented here. See `docs/SHUTDOWN_CHECKLIST.md`.
